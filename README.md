# GlobusSoft Assignment

This repository contains solutions for the GlobusSoft assignment.

## Tasks

### Task 1 - Amazon Laptop Scraper
- Scrapes laptop data from Amazon India
- Extracts title, price, rating, image URL, and ad/organic status
- Saves results to CSV

### Task 2 - Drone Detection API
- Flask API for drone detection
- Upload image and detect drones
- Returns detected drone count and annotated image
